# Third-party license sources

`THIRD_PARTY_LICENSES.txt` is generated by `scripts/third_party_licenses.py`
from the locked Cargo graph and is included in the core wheel. The inventory
conservatively includes build, test, and platform-specific crates as well as
runtime dependencies. Python runtime dependencies are installed separately and
ship their own notices.

`upstream/` retains license texts missing from published crate archives, with
repository revisions and original URLs in each `source.json`. If a crate omits
license text both in its archive and repository, its declared SPDX license text
is reproduced with the authors from its package metadata; no new copyright
ownership or year is invented. `MIT.txt` is the SPDX license-list-data canonical
MIT text (https://github.com/spdx/license-list-data/blob/main/text/MIT.txt).
For dual-licensed crates missing texts, the Apache-2.0 option is reproduced.

The MPL-2.0 component, colored, is unmodified. Its source is available at the
exact crate version's source/archive URL listed in the generated notice.
The local tk-serialize modification is documented in its PATCH.md and marked
in the modified source file.
