# Phase B serial image-path conformance

Phase B composes the hash-validated chat renderer/tokenizer, bounded image
decode and resize, RGB normalization/patchification, grids, prompt replacement
ranges, and conditional official output keys into
`QwenImageProcessor::prepare`. It is a serial, single-request image path; batch
planning/destinations, Python bindings, video, and parallel execution remain
later phases.

The public result retains the rendered and expanded prompt plus all original
code-point, expanded code-point, and expanded-token replacement spans. Image
occurrence metadata records message/content/input order, grid row, pixel-row
range, source dimensions, and prepared geometry. Production results do not
retain prepared RGB buffers. The explicit `prepare_with_media_trace` entry
point moves the same-pass prepared RGB buffers into a conformance trace; it
does not decode or transform an occurrence twice, and its additional retained
memory is exactly the sum of those RGB buffer lengths.

## Committed oracle

`reference/phase-b/v1/manifest.json` is generated by the pinned official
Python composition and authenticates its generator, compatibility manifest,
source blob, every source slice, expected blob, and every expected slice. Five
cases run against both immutable profiles:

- text-only conditional outputs;
- one padded-stride caller-owned RGB image;
- one JPEG with vision identifiers;
- interleaved PNG, lossless WebP, and lossy WebP; and
- occurrence references `[1, 0, 1]` with distinct per-occurrence resize
  options.

The corpus records exact rendered/expanded UTF-8, all three replacement span
coordinate systems, every official key/shape/dtype/stride/value, and each
prepared RGB stage result. The Rust report emits max absolute error, RMSE,
p50/p90/p99 absolute error, count over the frozen bound, maximum ULP distance,
and the first differing coordinate. Final pixel coordinates decode to
occurrence, grid row, patch row, channel, temporal offset, and patch x/y.
Lossless prepared RGB is exact; JPEG/lossy-WebP prepared RGB uses the frozen
one-byte bound. The current final tensors are checked exactly, which is
stronger than the immutable lossy end-to-end allowance.

## Offline commands

The normal candidate gate runs Rust only and performs no Python, Hugging Face,
Qwen VL Utils, Pillow, or TorchVision work at runtime. It requires both pinned
tokenizer/template snapshots under `reference/.cache/huggingface`:

```bash
make phase-b-conformance
```

Override `PHASE_B_ASSETS_ROOT` for another local cache and
`PHASE_B_REPORT_OUTPUT` for the JSON report destination. The executable can
also run one profile with `--profile qwen3-vl-8b` or
`--profile qwen3.5-9b`.

Regeneration is an oracle-maintainer operation and does invoke the exact pinned
Python environment:

```bash
make phase-b-conformance-regenerate
```

Regenerate only when the accepted compatibility contract or corpus source
changes. Generate twice to temporary output directories and compare all three
files before replacing the committed corpus.
