# C3: Pass the full image conformance gate

## Goal

Validate the installed Python-facing Rust batch path against the complete A3
text/image compatibility corpus for both frozen model profiles and publish the
first reproducible conformance report. Closing this ticket is the correctness
gate that permits Phase D profiling and performance work to begin.

## Scope

- Run the C2 Python batch API against every declared committed and live
  differential text/image case from A3 for both pinned profiles.
- Compare rendered/expanded prompts, conditional key presence, dtypes, shapes,
  strides, IDs, masks, modality IDs, grids, offsets/ranges, placeholder counts,
  occurrence order, prepared RGB, final pixels, and stable error categories
  under the frozen exact/numeric comparison policy.
- Exercise heterogeneous multi-request batches and batch permutations, not only
  the Phase B single-request cases, including boundary dimensions, codecs/color
  modes, raw strided RGB, malformed media/messages, interleaving, repetition,
  and resource/overflow failures.
- Publish a machine-readable result and readable summary with profile, source,
  artifact, package, platform, command, and comparator provenance sufficient to
  reproduce the gate from a clean checkout.
- Keep correctness evidence separate from diagnostic timing. Fail the gate on
  missing outputs, widened tolerances, skipped declared cases, or fallback to
  the official implementation inside the candidate path.

## Non-goals

Do not claim or certify speed, add parallelism or fusion, expand the frozen
compatibility envelope, add video parity, or implement vLLM production
integration.

## Acceptance Criteria

- [ ] Qwen3-VL-8B-Instruct and Qwen3.5-9B pass the entire declared A3
      text/image corpus through the installed C2 Python API with no undeclared
      skips or candidate-path Python/Hugging Face/Qwen VL Utils fallback.
- [ ] All discrete metadata, output keys, dtypes, shapes, strides, padding,
      ordering, and stable valid/invalid error categories match exactly.
- [ ] Prepared RGB and `pixel_values` satisfy the immutable per-stage and
      end-to-end tolerances, with full mismatch localization and ULP/error
      diagnostics retained on failure.
- [ ] Heterogeneous batch and permutation cases prove request, occurrence,
      token, patch, and grid order is deterministic and independent of grouping.
- [ ] A versioned machine-readable conformance report and human-readable summary
      are committed with complete reproducibility and provenance metadata.
- [ ] The report contains no performance claim, and the benchmark tooling cannot
      mark an image speed result releasable unless this gate is current and
      passing.
- [ ] Report validation, a clean reproducibility run, wheel build/install smoke,
      and the full repository correctness suite pass.
