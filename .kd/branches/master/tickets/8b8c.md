# Make single-image memory gate measurable and passing

## Goal

Make the `image1/t1` transient-memory comparison repeatably measurable and
passing for every selected profile/architecture coordinate, distinguishing
real candidate peak usage from process-RSS floor and sampling artifacts.

## Scope

- Reproduce the zero or very small official external-RSS deltas and inspect
  allocator, sampling-boundary, process-baseline, and exact native-peak data.
- If the versioned measurement protocol is defective, fix it transparently,
  add regression tests, and require entirely fresh evidence; never relabel an
  old archive.
- Reduce actual candidate peak use where the measurement is sound.

## Non-goals

Do not weaken the `<=0.5` ratio, drop zero-denominator repetitions, add a
hidden floor after capture, or declare an unmeasurable coordinate passing.

## Acceptance Criteria

- [ ] `memory/arm64/qwen3.5-9b/image1/t1`,
      `memory/x86_64/qwen3-vl-8b/image1/t1`, and
      `memory/x86_64/qwen3.5-9b/image1/t1` each have positive official
      denominators in every repetition and every paired candidate ratio
      `<=0.5`.
- [ ] Tests cover zero/near-zero denominator behavior and preserve exact native
      peak accounting; any protocol change is versioned and invalidates stale
      captures.
- [ ] Evidence clearly separates measurement-floor effects from substantive
      candidate allocations and records the chosen remedy.
- [ ] Full image conformance, repository correctness, and D4 evidence
      validation pass with fresh exact-source provenance recorded.
