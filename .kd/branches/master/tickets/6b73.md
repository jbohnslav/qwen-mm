# B4: Implement raw-RGB normalize and patchify

## Goal

Prove the model's visual tensor layout from canonical already-prepared RGB,
isolating normalization and patchification from codec and resize differences.

## Scope

- Consume dimensions and grids from B3 plus an already-sized packed HWC RGB8
  raster whose bytes are authoritative.
- Match the frozen mean/std normalization, still-image temporal duplication,
  channel/temporal/spatial permutation, patch flattening, row ordering, and
  grid/patch-count invariants shared by both profiles.
- Materialize parity-facing C-contiguous `float32` patch rows and `int64`
  `image_grid_thw` through B1's output types.
- Detect input-length, dimension, capacity, and internal-plan inconsistencies
  before unsafe indexing or partial output.

## Non-goals

Do not decode formats, convert color modes, resize pixels, accept arbitrary raw
strides, parallelize, fuse for speed, expose Python arrays, or implement video
sampling. Raw-frame temporal support belongs to Phase E.

## Acceptance Criteria

- [x] From identical prepared RGB, every compared `pixel_values` element is
      within `rtol=0`, `atol=1e-6`, with exact shape `[patches, 1536]`, row
      order, C strides, and `float32` dtype semantics.
- [x] `image_grid_thw` is exact `int64`; its product, merge factor, placeholder
      count, and emitted patch rows satisfy the A3 invariants for every case.
- [x] Tests cover constant/channel-coded pixels, odd source dimensions after
      B3 planning, aligned/no-op geometry, minimum/maximum boundaries, multiple
      aspect ratios, and both frozen profiles.
- [x] Still-image temporal duplication and the complete Qwen permutation/
      flattening order are independently asserted so symmetric fixture data
      cannot hide a layout error.
- [x] Input-length mismatch, stale/inconsistent plans, resource excess, and all
      capacity/offset products fail with the correct stable category before
      writing a partial result.
- [x] Stage comparisons emit A3's required numeric diagnostics on failure;
      core unit/doc tests, conformance-smoke, format, and Clippy checks pass.
