# Phase A: Freeze truth and high-risk seams

## Goal

Close the reference, contract, tooling, benchmark, and vLLM-integration unknowns
that would otherwise force rework in the Rust implementation. This epic covers
Phase A of `ROADMAP.md`; it does not implement the processor itself.

- A2 / `9754` — build the golden reference exporter.
- A3 / `431a` — build the conformance corpus and comparator.
- A4 / `e26c` — bootstrap the Cargo workspace and CI.

benchmark, and vLLM work to proceed in parallel when their prerequisites close.
