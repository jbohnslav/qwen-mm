# Close single-request and batch-padding API deltas

Remove remaining request ceremony and match official batch-generation behavior.

## Acceptance Criteria

- [x] A concise single-request helper prepares a messages list without the
      `prepare_batch` request wrapper and exposes common chat options as keyword
      arguments.
- [x] The existing `prepare_batch` API remains available for heterogeneous and
      preloaded-media workloads.
- [x] Left padding is supported explicitly and tested for batched generation compatibility; the default and metadata contract are documented.
- [x] Prepared outputs have concise mapping-style access without losing the arrays and metadata separation.
- [x] README and installed-wheel tests cover the new helper, text-only and image requests, left-padded batches, and compatibility with the existing API.
